# 求职助手 · AI 岗位匹配分析

基于 Coze 工作流的求职匹配应用：输入三个顺位的求职意向与个人经历，AI 自动联网检索真实招聘信息，逐岗位完成匹配度评分、优势/差距分析与补充建议，生成完整的求职分析报告。

**在线体验：https://unim1012-netizen.github.io/**

## 功能特性

- 三个顺位的求职意向输入（企业类型严格枚举 + 意向职位），支持并行检索更多岗位机会
- 自动联网检索**真实招聘信息**（可链接回溯、可查证，禁止编纂）
- 逐岗位匹配分析：匹配度评分、可视化对比、优势点识别、差距分析与补充建议
- 智能分支输出：匹配度高时给出**简历优化 + 面试准备建议**；匹配不足时给出**职业发展建议 + 技能学习路径 + 综合分析**
- Markdown 报告渲染、一键复制、桌面/移动响应式适配

## 系统架构

```
┌─────────────┐    fetch     ┌──────────────────────┐   HTTPS   ┌──────────────────┐
│  前端页面    │ ───────────▶ │  Cloudflare Worker    │ ───────▶ │  Coze 工作流 API  │
│ GitHub Pages │ ◀─────────── │  代理（跨域 + Token）  │ ◀─────── │  dfkb7x84cj…      │
└─────────────┘  JSON 响应   └──────────────────────┘   轮询    └──────────────────┘
```

- **前端**：单文件 HTML/CSS/JS 应用，托管于 GitHub Pages
- **代理层**：Cloudflare Worker 解决浏览器跨域（CORS）限制，Coze API Token 仅保存在服务端，不暴露给浏览器
- **工作流**：Coze AI 编程平台设计的 14 节点工作流（意向解析 → 三路并行招聘检索 → 匹配分析 → 分支输出），发布为 API 服务
- **调用方式**：异步任务执行（`/async_run`）+ 轮询查询（`/task/{id}`），适配工作流长耗时场景

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生 HTML / CSS / JavaScript（单文件自包含，无构建依赖） |
| 代理 | Cloudflare Workers（Service Worker 格式，CORS 转发） |
| 工作流 | Coze AI 编程平台（web-search 联网检索 + LLM 分析） |
| 托管 | GitHub Pages |

## 关键设计

- **Token 安全**：API Token 仅存在于 Cloudflare Worker 服务端，前端与代码仓库均不含凭据
- **参数校验**：第二/三顺位留空时整体省略字段（Coze 部署 API 严格要求，空字符串会返回 201002）
- **错误分级**：对参数校验、额度不足（604001）、网络异常等场景提供针对性提示
- **异步执行**：工作流运行 1–3 分钟，采用异步提交 + 轮询模式，避免同步请求超时
